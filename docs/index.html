Built for the RF Waveband 2

Waveband 2 uses radio—not infrared. These signals run through the Flipper Zero's built-in CC1101 using the standard Sub-GHz Saved interface.

◉

Confirmed group 0

The persistent red reference was physically confirmed. Every color uses the same universal group-0 structure.

⌁

Corrected protocol

Uses the proper on-air 6b/8b orientation and CRC-12 bit order, with automated known-vector tests.

⚡

Fast after waking

Wake once with a self-contained command, then switch colors or turn off in about one second.

Why the first command takes 18 seconds

The wristband aggressively sleeps to preserve its coin cells. A one-press signal first sends valid black packets long enough to wake the RF receiver, then sends the selected persistent color.

336 wake framesApproximately 16.6 seconds of valid black group-0 traffic
→
20 action framesApproximately one second of persistent color or OFF

Once awake, use the quick_after_wake files for near-instant control. If they stop responding, the wristband has gone back to sleep.

Colors and a real OFF command

OFF uses the same working persistent packet with all RGB channels set to zero. Maximum white and lower-current soft white are both included.
